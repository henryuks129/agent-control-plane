After a design run, ACP looks through the changed front-end files for the patterns below. A finding is a pattern match with a file and a line, so it is evidence and appears that way in Review. Taste is left to people, and to reviewers whose comments are marked as opinion.

RuleLooks forWhat to do
placeholder-textLatin filler text left in the pageWrite the real copy.
dead-linkA link that goes nowhere: a bare hash, an empty link or a script linkPoint the link somewhere, or make it a button that does something.
image-without-altAn image with no alt textAdd alt text, or an empty alt if the image is decoration.
gradient-textText filled with a gradient by clipping the background to itShow emphasis with weight or size.
hard-offset-shadowA shadow with an offset and no blurGive the shadow a blur, or remove it.
side-stripe-borderA left or right border of 2px or moreUse a full border, a background, or spacing to set the item apart.
focus-outline-removedThe focus outline removed in a file with no keyboard focus styleKeep a visible focus style.
motion-without-reduced-motionAnimation in a file that never handles the reduced-motion settingRespect the reader's reduced-motion setting.

From design-library/anti-patterns/ai-slop.md

Never ship by default: arbitrary gradients, random glass effects, excessive rounded cards, generic dashboards, random floating blobs, random icons, inconsistent radii and shadows, arbitrary animation, duplicated components, placeholders, fake metrics, dead buttons, invented interactions.

The library is governed design knowledge. An entry moves through reference → candidate → reviewed → canonical → deprecated. Agents may add candidates; a change to a canonical entry needs your approval.
