This folder is not a Git repository. ACP needs Git to give each agent its own worktree and to show you what changed.

To use this folder, make it a repository first. This adds a hidden .git folder and changes none of your files.

git -C /Users/you/Documents/notes init

ACP does not run this for you: creating a repository is your decision.

This project has no memory yet

Optional, and you can do it later

Memory is a few plain files in the project that every agent reads before it works. Setting it up will:

  • create .acp/knowledge.md with empty Goals, Rules and Decisions headings
  • create the folder .acp/rules/ for rules that apply to some files only
  • add .acp/local/ to .gitignore, where checkpoints and proposals stay on this computer

It never overwrites a file you already have, and it commits nothing. You review and commit the new files like any other change.

or run it yourself:
acp /memory init

Found AGENTS.md and CLAUDE.md in this project. After setup their contents are offered as import proposals for you to accept or reject; the files themselves are left as they are.
