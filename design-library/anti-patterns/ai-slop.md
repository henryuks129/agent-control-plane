# AI Slop Guard

## Never ship by default
- arbitrary gradients
- random glassmorphism
- excessive rounded cards
- generic SaaS dashboards
- random floating blobs
- random icons
- inconsistent radii/shadows
- arbitrary animation
- duplicated components
- placeholders
- fake metrics
- dead buttons
- invented interactions

## Pre-flight
1. Search the design library.
2. Search the codebase.
3. Reuse or extend existing primitives.
4. Verify responsive, accessibility, loading, empty and error states.
5. Confirm visual hierarchy and interaction intent.
