# ACP Design Library

The design library is governed UX/design knowledge, not a screenshot dump.

## Lifecycle

`reference → candidate → reviewed → canonical → deprecated`

Candidates may be generated/imported from references. Canonical rules require approval.

## Reference inputs

- Impeccable — https://impeccable.style/
- Taste Skill — https://www.tasteskill.dev/
- Higgsfield MCP — https://higgsfield.ai/mcp

- Dribbble Web Design — https://dribbble.com/shots/popular/web-design
- Motion Sites — https://motionsites.ai/

## Anti-slop policy

Reject arbitrary gradients, random glassmorphism, excessive rounded cards, generic SaaS dashboards, random floating blobs/icons, inconsistent radii/shadows, arbitrary animation, duplicated components, placeholders, fake metrics, dead buttons and invented interactions unless explicitly required by the product.

## Import rule

Reference → analyze → extract rules/patterns → candidate → review → canonical. Do not automatically copy external code or assets; licensing and attribution remain explicit concerns.

## Agent retrieval rule

Agents retrieve only entries relevant to the task. They must search the library before creating a new reusable component or design pattern.
