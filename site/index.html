How it works

ACP doesn't replace your agents. It connects them, gives them one shared memory, and keeps a person in charge of what changes.

  1. 01

    Connect what you have

    Sign in to Claude Code, Codex or Antigravity in their own apps. ACP starts them for you and never sees your password or tokens. No paid plan? Use free models through OpenCode.

  2. 02

    Pick an orchestrator

    Star one or two agents. They talk through your goal, split it into tasks and hand each task to the model best suited to it.

  3. 03

    Work runs in parallel

    Each task runs in its own Git worktree. If an agent stops or its plan runs low, another picks up from the latest checkpoint, not the whole chat.

  4. 04

    You approve every change

    Each change is tested and scanned and arrives with a report. Approved changes merge one at a time, with checks run again after each.

shared memory

Switch agents without writing a briefing.

Claude, ChatGPT and Gemini each keep their own memory, locked in their own app. ACP keeps one memory for every agent you connect, owned by you.

Project memory lives in your repository, so it's reviewed like code and works even without ACP running. ACP also writes it into the AGENTS.md and CLAUDE.md files your agents already read.

review and safety

Evidence first, opinions labelled.

Every change runs the same checks, whichever model wrote it. Tool results are shown as evidence. Comments from AI reviewers are marked as opinion, so you know which is which.

  • ✓ Tests and types
  • ✓ Stays inside its scope
  • ✓ No secrets committed
  • ✓ Known-vulnerable packages
  • ✓ Security patterns
  • ✓ Dead code and duplicates
